An alien tourist hands planet Earth a one-star review — and still admits
the food was excellent. Entry for the
[make.fun bounty](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7).

## The entry

> One star: I flew 40 light-years for the biryani and stayed for the
> mangoes, but Earth charges rent for gravity.

111 characters, one sentence. The compliment is the journey itself: the
tourist crossed the galaxy for the biryani and stayed for the mangoes.
The grievance is pure outsider bafflement — a planet that charges rent
for gravity.

## Run

```sh
python3 main.py
```

Writes one sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
`main.py` validates the text against the bounty gate first (1–200
characters, not only white space, exactly one sentence) and reads the
file back to prove it is byte-identical to the entry.
